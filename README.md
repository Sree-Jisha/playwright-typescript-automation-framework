Playwright TypeScript Automation Framework

About This Project

This repository contains an independent test automation framework developed using Playwright and TypeScript.

The objective is to demonstrate practical automation testing skills through UI automation, API testing, reusable frameworks and real-world testing scenarios.

About Me

I am a QA professional with extensive experience in the banking domain, specialising in functional testing, end-to-end testing, regression testing and test automation.
